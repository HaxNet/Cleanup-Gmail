Reading pane

Reply width only applies when “Reply bar matches card width” is off.

Cards need “Float messages as cards” on (Reading section below). Canvas applies in light mode; dark themes get a matching dark canvas automatically.

Row colors

Gmail leaves unread rows transparent, so they take on the canvas color. These override both. Set thickness to 0 for no lines. Row colors are ignored in dark themes.

Backup & transfer

Dragging the file onto the box is the most reliable — a file dialog can close this popup. If it does, open this panel in a tab and use Choose file there.

Advanced — your own CSS

Injected into Gmail after everything else. Use it to hide anything this panel misses: right-click the element in Gmail → Inspect → copy its class → .thatClass { display:none !important }
